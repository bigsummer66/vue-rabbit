# 栖川里物项目包装文案

## 项目一句话介绍

栖川里物是一个面向都市消费人群的品质生活方式零售前台项目，覆盖商品浏览、SKU 选择、购物车、结算下单、支付回跳和会员中心等核心交易链路。

## 简历版项目描述

负责基于 `Vue 3 + Vite + Pinia + Element Plus` 搭建零售电商前台 SPA，完成首页推荐、分类浏览、商品详情、购物车、结算、支付结果页与会员中心等模块开发，并通过状态持久化、路由鉴权、登录回跳、图片懒加载和 SKU 规格联动等方案提升页面体验与业务完整性。

## 简历亮点拆分

- 基于 Vue 3 组合式 API 拆分首页、分类、详情、交易与会员模块，完成完整前台业务链路搭建。
- 封装 Axios 请求层与全局拦截器，统一处理接口请求、登录失效、错误提示和页面跳转逻辑。
- 使用 Pinia 管理用户状态与购物车数据，支持本地持久化与登录后购物车合并。
- 实现 SKU 规格联动、图片懒加载、骨架屏与登录回跳，优化首屏体验和关键流程可用性。

## 面试讲述版本

### 版本一：偏业务

这个项目我把它包装成了一个生活方式零售品牌“栖川里物”的前台商城，重点不只是商品展示，而是完整交易链路的承接。用户可以从首页内容推荐进入分类和详情页，完成 SKU 选择、加入购物车、结算下单、支付回跳，再到会员中心查看订单，整体更接近真实电商前台。

### 版本二：偏技术

技术上我主要用 Vue 3 组合式 API 做页面和逻辑拆分，用 Pinia 管理用户和购物车状态，通过 Axios 拦截器处理鉴权和异常提示，再结合路由守卫实现登录回跳。商品详情页里还做了 SKU 规格联动，首页部分补了懒加载和骨架屏，整体目标是让它既像一个完整业务项目，也体现前端工程化能力。

## 可直接复制到简历的三条要点

1. 独立完成基于 Vue 3 的零售商城前台项目开发，覆盖首页推荐、分类浏览、商品详情、购物车、结算下单、支付回调与会员中心等核心模块。
2. 通过 Pinia、Axios 拦截器与 Vue Router 守卫实现用户状态管理、登录鉴权、购物车持久化和登录回跳，提升业务流程完整性与项目可维护性。
3. 实现 SKU 规格联动、图片懒加载、骨架屏和异步状态封装，优化商品选购与首页首屏体验。

## 包装建议

- 简历里优先写“品质生活方式零售商城前台”或“精选零售电商前台 SPA”，不要写“练手项目”。
- 如果面试官追问数据来源，可以表述为“基于既定接口协议完成前台业务实现与交互封装”。
- 如果需要解释体验账号，可以表述为“项目内置演示账号，便于快速展示完整交易路径”。
