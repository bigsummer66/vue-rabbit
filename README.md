# 栖川里物前台商城

一个基于 `Vue 3 + Vite + Pinia + Element Plus` 搭建的品质生活方式电商前台项目。项目以“栖川里物 ChicValley”作为品牌设定，围绕精选家居、餐厨器物、日用好物与会员复购场景，覆盖首页推荐、分类浏览、商品详情、SKU 选择、购物车、结算下单、支付回跳和会员中心等完整业务链路。

## 项目定位

- 项目类型：生活方式零售品牌前台 SPA
- 品牌设定：面向 25-35 岁城市消费人群的精选零售平台
- 业务目标：通过内容化推荐与标准化交易流程，提升首购转化与会员复购体验
- 适用场景：前端简历项目、业务型作品集展示、Vue 3 工程化能力证明

## 核心功能

- 首页承载分类导航、Banner、专题推荐、新品与人气商品展示
- 分类页支持一级分类、二级分类、商品筛选与分页式列表浏览
- 商品详情页支持 SKU 联动、数量选择、图片预览与加入购物车
- 购物车支持勾选结算、数量编辑、删除与金额汇总
- 结算页支持地址、配送、支付方式选择与订单提交
- 支付页支持订单倒计时、支付跳转与支付结果回调展示
- 会员中心支持个人信息查看与订单列表管理

## 技术实现

- 使用 Vue 3 组合式 API 拆分业务页面与复用逻辑，保持页面职责清晰
- 通过 `Pinia + pinia-plugin-persistedstate` 管理用户信息与购物车状态，支持本地持久化
- 封装 Axios 请求实例与拦截器，统一处理接口请求、鉴权失效和错误提示
- 结合路由懒加载、前置守卫与登录回跳，完善页面访问控制与导航体验
- 基于自定义 SKU 规格联动逻辑处理无库存选项禁用与可售路径计算
- 使用图片懒加载、骨架屏与异步状态封装优化首页首屏感知体验

## 本地运行

### 环境要求

- Node.js `^22.18.0` 或 `>=24.12.0`

### 安装依赖

```bash
npm install
```

### 启动开发环境

```bash
npm run dev
```

### 构建生产包

```bash
npm run build
```

### 代码检查

```bash
npm run lint
```

### 运行测试

```bash
npm test
```

## 项目结构

```text
src
├─ apis          # 按业务模块拆分接口
├─ components    # 全局通用组件
├─ composables   # 复用型组合式逻辑
├─ directives    # 自定义指令
├─ router        # 路由与访问控制
├─ stores        # Pinia 状态管理
├─ styles        # 样式变量与通用样式
├─ utils         # 工具函数与业务辅助逻辑
└─ views         # 页面级业务模块
```
